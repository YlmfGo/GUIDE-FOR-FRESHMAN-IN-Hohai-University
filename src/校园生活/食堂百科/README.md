# 河海大学食堂百科

欢迎来到河海大学食堂百科！本指南将帮助你了解河海大学各校区的食堂信息，让你能够更好地规划你的饮食生活。

:::caution
本"百科"当前窗口与菜品并不完全,不能代表食堂全貌
:::

:::tip
目前江宁有两个食堂**叠翠山食堂（快乐食间）**,**将军山食堂**。总体上快乐食间是优于将军山的。
:::

:::tip
目前金坛有三个食堂**1 食堂**,**2 食堂**,**3 食堂**。总体上**1 食堂独领风骚**。
:::
